## Definition
The problem is posed in a coordinate frame with a geometric singularity on the domain
(`r=0` axis or the polar axis of cylindrical/spherical/axisymmetric frames), so validation must
account for the coordinate singularity.

## Params schema
None.

## Notes
Typically accompanies `cylindrical` / `spherical` / `axisymmetric` coord-systems whose domain
includes the axis. Part of the identity signature (§2.1 item 2); a searchable descriptor, not a
capability fork.
